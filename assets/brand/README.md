# ToBump — celostna grafična podoba (v2)

## Ideja
ToBump = povezovanje prijateljev okoli aktivnosti. Fist-bump = dogovor, energija, skupaj.

UI je **pesek**, akcija je **globok teal**. Teal je samo na gumbih, aktivnih chipih, ikonah in znamki — ne kot ozadje celotnega zaslona.

## Tipografija
- UI: obstoječi sistemni / Expo fonti (zaenkrat)
- Wordmark občutek: zaobljen geometric sans, medium weight, `Tobump` (T velika)

## Ton
Prijateljski, aktiven, umirjen za dolgo branje — papir, ne belina; teal kot poudarek, ne poplava.
