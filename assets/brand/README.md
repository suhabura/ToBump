# ToBump — celostna grafična podoba (v3, Igrišče)

## Ideja
ToBump = povezovanje prijateljev okoli aktivnosti. Fist-bump = dogovor, energija, skupaj.

Dve vlogi:
- **Organizacija** = travnata zelena (navi, chipi, znamka)
- **Gibanje / Join** = terakota (glavni CTA)

Ozadje je žajbljev kamen, ne belina in ne kava.
