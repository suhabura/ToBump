# ToBump — celostna grafična podoba (v1)

## Ideja
ToBump = povezovanje prijateljev okoli aktivnosti. Fist-bump = dogovor, energija, skupaj.

## Logo
| Različica | Datoteka | Uporaba |
|-----------|----------|---------|
| Horizontalni | `logo-horizontal.png` | splet, header, marketing |
| Znamenje (mark) | `mark.png` | favicon, splash, majhne površine |
| App ikona | `app-icon.png` | iOS / Android |

**Ne:** raztezati, spreminjati razmerij, dodajati senčenja, menjati barve ikone naključno.

## Tipografija
- UI: obstoječi sistemni / Expo fonti (zaenkrat)
- Wordmark občutek: zaobljen geometric sans, medium weight, `Tobump` (T velika)

## Ton
Prijateljski, aktiven, jasen — brez “corporate cold”, brez preveč igračkastih emoji v UI.
